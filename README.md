# ShopSphere 🛒

A full-stack **E-Commerce web application** built using the **MERN Stack**. Users can browse products, manage their cart and wishlist, place orders, and manage their accounts.

## 🚀 Features

* 🔐 User Authentication & JWT Authorization
* 🛍️ Product Listing & Product Details
* 🛒 Shopping Cart Management
* ❤️ Wishlist
* 📦 Order Management
* ⭐ Product Reviews & Ratings
* 👤 User Profile
* 🛠️ Admin Dashboard & Product Management
* 🔒 Protected Routes

## 🧑‍💻 Tech Stack

**Frontend:** React.js, Vite, Tailwind CSS, Axios, React Router
**Backend:** Node.js, Express.js, MongoDB, Mongoose, JWT
**Deployment:** Vercel, Render & MongoDB Atlas

## 📁 Project Structure

```text
shopsphere/

```

## ⚙️ Installation

### Clone the repository

```bash
git clone <your-repository-url>
cd shopsphere
```

### Install and run Frontend

```bash
cd client
npm install
npm run dev
```

### Install and run Backend

```bash
cd server
npm install
npm run dev
```

## 🔐 Environment Variables

**Server `.env`**

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
CLIENT_URL=http://localhost:5173
```

**Client `.env`**

```env
VITE_API_URL=http://localhost:5000/api
```
